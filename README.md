# 🎮 键盘小勇士 - Typing Game

> 给 typing_game 小朋友的打字练习游戏 ✨

一款专为儿童设计的打字练习游戏，支持 **英文** 和 **拼音** 双路径学习。
由 Tauri + Vue 3 + Rust 驱动，桌面端体验流畅。

---

## 📸 预览

| 关卡选择 | 游戏中 | 成就弹窗 |
|---------|--------|---------|
| 22 个关卡，渐进难度 | 单词下落 + 虚拟键盘 + 粒子特效 | 12 个成就等你解锁 |

---

## ✨ 功能特色

- 🎯 **双路径学习** — 英文（12 关）和拼音（10 关），涵盖字母→单词→句子→段落
- 📈 **渐进难度** — 每关速度递增 0.05，让小朋友感受"又快了那么一点点"
- ⌨️ **真实键盘布局** — 虚拟键盘按 ANSI 标准错位排列，匹配真实手感
- 🏆 **成就系统** — 12 个成就，打完实时弹出，激励持续练习
- 📊 **个人中心** — 累计打字数、最高连击、通关进度一目了然
- 💾 **成绩存档** — 本地持久化，不丢数据
- 🎵 **音效反馈** — 打字音、连击音、错误提示，沉浸体验
- 💥 **粒子特效** — 正确打字时华丽爆炸

## 🚀 快速开始

### 前置条件

- [Node.js](https://nodejs.org/) >= 18
- [Rust](https://www.rust-lang.org/) (运行 `install-rust.bat` 自动安装)
- Windows / macOS / Linux

### 启动

```bash
# 方式 1：启动菜单
start-all.bat

# 方式 2：纯 Web 预览（最快）
cd typing-kids
npm install
npm run dev
# 打开 http://localhost:3000

# 方式 3：Tauri 桌面应用
cd typing-kids
npm install
npm run tauri:dev
```

### 构建

```bash
cd typing-kids
npm run tauri:build
# 产物在 src-tauri/target/release/
```
